Yet another Leet Code Tracker with extra features such as-

1. Attempt Counter and Spaced Repetition: To make sure you have grasped the pattern and gained solid understanding repetition is a must!
2. Due Date Filter: Based on the number of attempts, a date is assigned for the next attempt. If that day has already passed you get filtered problems to repeat.
3. Framework for Solving Problems: This only works for beginners (something which I personally used). Understand-Every-Problem-Solve-Right is what I remember when solving the problems to stay grounded. Source: [How to Solve It](https://en.wikipedia.org/wiki/How_to_Solve_It)


**Note:** Progress **Must be saved** manually time to time (`import as json`). Clearing the Browser Cache will reset it. Recommended to save it in the Cloud.
